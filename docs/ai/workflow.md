# AI Coding Workflow

Use this workflow for every non-trivial change:

1. Create or update feature spec.
2. Clarify ambiguous requirements.
3. Generate checklist.
4. Generate implementation plan.
5. Generate tasks.
6. Analyze consistency across spec, plan, and tasks.
7. Implement tasks in order.
8. Run relevant tests.
9. Update tasks and ADRs.
10. Summarize changed files, tests, architecture impact, and risks.

Completion format:

```text
Feature:
Completed tasks:
Changed files:
Architecture impact:
Tests run:
Spec consistency:
Risks:
```
